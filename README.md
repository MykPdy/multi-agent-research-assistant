# Multi-Agent Research Assistant

A production-style Multi-Agent Research Assistant built using:

- LangGraph
- LangChain
- Groq (Llama 3.1 70B)
- Gemini 2.0 Flash
- Tavily Search
- DuckDuckGo Search
- Streamlit
- ReportLab

## Architecture

Research Agent
→ Critic Agent
→ Research Agent (if needed)
→ Writer Agent
→ Reviewer Agent

## Features

- Multi-agent reasoning
- Iterative research loops
- Web search integration
- Citation generation
- PDF export
- Streamlit UI
- Caching
- Structured logging
